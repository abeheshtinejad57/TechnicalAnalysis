## How to run
1. Open RStudio.
2. Open `Beheshtinejad_Ali_BDA400_A02.R`.
3. Run the entire script from either the repository root or the `Assignment_2` folder.
4. Confirm the five symbols are imported and separate data frames such as `AAPL_data` are created.
5. Review the moving average, mean, mode, median, and standard deviation output.
6. Run `Beheshtinejad_Ali_BDA400_A02_Display.R` to reproduce the dedicated display and visualization section.
